## Title

Hindsight — the YouTube narrative map

## Description draft

Hindsight helps viewers, researchers, and creators explore how YouTube channels talk about issues and how their framing changes over time. It connects a visual archive of topics, channels, and videos with an agent that can investigate the indexed catalogue and open supporting transcript moments inside the app.

The agent uses application context, including the current channel and draft editor, and can run a draft check, display the result, and open a source. The animated landing map lets users hover over issue clusters and open the original Galaxy focused on a selected issue. A featured three-video story feeds source context into the agent; suggested prompts trigger transcript inspection, comparison, and an in-app source card.

All collected transcripts come from **Perspectivity.co as existing work**. The original engine, visual studio and corpus are inherited; the event work adds the agent, streaming transports and CopilotKit integration. This document does not assert organizer-confirmed eligibility.

The user reports that an initial submission has already been made. This file is a draft for any authorized update, not evidence that the portal was changed.
